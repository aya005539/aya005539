
# أهلاً بك! أنا أية مصري 👋
### مهندسة أنظمة حاسوب ومطورة حلول برمجية مدعومة بالذكاء الاصطناعي 💻✨

خريجة هندسة أنظمة الحاسوب من الجامعة العربية الأمريكية في جنين، وأمتلك خبرة عملية في تطوير تطبيقات الويب، بناء قواعد البيانات، وأتمتة العمليات التقنية والتشغيلية في المؤسسات والمصانع.

تعتمد منهجية عملي الحديثة في تطوير التطبيقات والنماذج الأولية على **هندسة الأوامر المتقدمة (Prompt Engineering)** وتوظيف أدوات الذكاء الاصطناعي لبناء الحلول البرمجية بسرعة وكفاءة عالية.

---

### 🛠️ المهارات والتقنيات (Tech Stack)
* **أساليب التطوير:** هندسة الأوامر (Prompt Engineering) وتوظيف أدوات الذكاء الاصطناعي في بناء البرمجيات.
* **لغات البرمجة والتقنيات:** HTML, CSS, JavaScript, Python, PHP, Java.
* **الأطر والمكتبات (Frameworks):** Laravel 9, Bootstrap, Flutter.
* **قواعد البيانات وأدوات التطوير:** MySQL, Git, GitHub, Replit (Cloud IDE & AI Prototyping), Microsoft Access.
